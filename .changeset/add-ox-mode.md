Add **`ox-mode`** (user-invoked) to the **Productivity** bucket. `/ox-mode` switches the agent into one working style for the session: it matches each task to a playbook (Investigation, Bug fix, Feature, Refactoring, Prototype, Authoring a skill, Eval, Autonomous run, Multi-phase plan, Session pickup, Pause safely, Worktree cleanup, Opening a PR), routes to the other skills at the steps that need them, verifies only with checks it can run itself, and writes short replies that cite the principles behind each decision. Babysit, Shipping, Orchestrate, Autopilot-full and Autopilot-stack run in T3 Code, using `gh` and plain-file state. Adapted from pstack-t3's `poteto-mode` (MIT), credited in the skill's `CREDITS.md`.
