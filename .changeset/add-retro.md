Add **`retro`** (user-invoked) to the **Productivity** bucket. It reads a coding session's log and suggests changes to the agent's environment, ordered by severity: navigation pointers, automated checks (LuaLS with fivem-lls-addon for Lua), review rules, oversized `AGENTS.md` files, expensive tool calls, no-op instructions and missing information. Adapted from Matt Pocock's `retro` (MIT), credited in the skill's `CREDITS.md`.
