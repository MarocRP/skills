Add **`no-comments`** (model-invoked) to the **Productivity** bucket. A fresh reviewer on the `review` model deletes the comments in a diff that the code should make unnecessary and flags the code behind them, then the agent fixes it. License headers, comments about natives or resources you don't own, LuaLS annotations and public API docs stay. Adapted from pstack-t3's `no-comments` (MIT), credited in the skill's `CREDITS.md`.
