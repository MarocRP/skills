Add **`pr`** (model-invoked) to the **Productivity** bucket. It writes pull request bodies in three sections: a Summary that shows the change as a call tree, file tree, Mermaid diagram or small diff, Evidence with a before and after, and Merge Danger, which names whether the change is a one-way door (a dropped column, a renamed item) and its blast radius. It follows the repo's own pull request template when there is one. Adapted from Matt Pocock's `pr` and Humanlayer's `show-me` (both MIT), credited in the skill's `CREDITS.md`.
