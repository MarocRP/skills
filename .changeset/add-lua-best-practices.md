Add **`lua-best-practices`** (model-invoked) to the **FiveM** bucket. It loads for `.lua` files and teaches how Overextended structures resources on ox_lib: `require` for code modules, `lib.load` and `lib.loadJson` for data, one entry script per side, convars for config, ox_lib's `cache`, `lib.onCache`, points, callbacks and locales, and the CfxLua syntax ox resources use. Checked against ox_lib 3.40.3 and ox_inventory 2.48.0.
