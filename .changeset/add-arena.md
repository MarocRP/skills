Add **`arena`** (model-invoked) to the **Productivity** bucket. It runs one task as several candidates on the `panel` models, has a `review` model on another family judge them against a rubric, picks the strongest as the base and grafts the best ideas of the others into it. Code-writing candidates each get their own git worktree. Adapted from pstack-t3's `arena` (MIT), credited in the skill's `CREDITS.md`.
