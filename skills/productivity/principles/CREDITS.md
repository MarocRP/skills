# Credits

Adapted from the `principle-*` skills in [pstack-t3](https://github.com/mariusflorescu/pstack-t3/tree/main/skills/), itself adapted from [pstack](https://github.com/cursor/plugins/tree/main/pstack) by Lauren Tan. The 23 principle skills are bundled as files of one skill with an index, instead of one user-invoked skill each. New here: FiveM boundaries (net events, NUI callbacks, exports, state bags, KVP, convars) in Boundary Discipline and Type System Discipline, LuaLS annotations as Lua's type system, resource restarts in Make Operations Idempotent and Fix Root Causes, and state bags and database rows in Separate Before Serializing Shared State. Explain the Number is left out.
